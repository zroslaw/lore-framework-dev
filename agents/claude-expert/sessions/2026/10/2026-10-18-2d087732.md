# Mapped the Claude agent-building options and Managed Agents

The session started as a series of plain questions from the user, before any agent was booted.
The user asked what the Claude Code Agent SDK is, then what the Tool Runner is, then how the two
differ. The user pushed several times for simpler wording ("in simple words"). The answers that
worked best were short: the Tool Runner is "a loop with your own tools only", and the Agent SDK is
"a Claude Code session in code". The user confirmed that the Tool Runner takes a normal `system`
prompt. The user also confirmed that the Agent SDK supports multi-turn sessions like the CLI, so
building a custom CLI client on it is easy.

Next, the conversation moved to Managed Agents. It covered the agent, session and environment
model, the extra features (vaults, schedules, outcomes, multiagent, memory stores), and how to get
context and data into a session. The bundled `claude-api` skill gave most of the answers. Two
facts were missing from it and came from platform.claude.com: the cloud sandbox specs (Ubuntu
24.04, up to 8 GB RAM, up to 10 GB disk) and the Files API limits (500 MB per file).

The main correction came when the user asked to run agents on about 15 GB of data with their own
Docker image. The cloud sandbox cannot do this: it has no custom image and its disk is too small.
The answer pointed the user to a self-hosted sandbox (own image, mounted volume, outbound-only
worker) or to the Agent SDK in the user's own container. The user then learned that environment
`packages` are cached across sessions, that packages the agent installs during a session are lost,
and that one environment can be set up for each task type and reused.

The session closed with use cases and a market check. Anthropic's Console quickstart templates
gave the typical use cases. A web search showed that the platform fee is small: $0.08 per active
session-hour plus model tokens, which make up most of the bill. Public adoption numbers are thin
(public beta since April 2026, some named launch customers), and AWS AgentCore, Vertex Agent
Engine, Foundry Agent Service and E2B/Daytona sandboxes are the main alternatives. Those
comparison figures come from third parties and do not always agree.

At the user's request, claude-expert was booted and an intermediate finalization was run. It
created a new developer-platform area in claude-expert's Lore. The user plans to continue the
session after this checkpoint.

## Learning

### claude-expert

- **What mattered:** Two questions separate the four Claude agent-building options: who supplies the harness, and who supplies the deployment. The options are a manual loop, the Tool Runner (your tools only), Managed Agents (hosted loop plus a sandbox) and the Agent SDK (the full Claude Code harness, self-hosted), and only Managed Agents gives a managed deployment. The Managed Agents cloud sandbox is a fixed Ubuntu image with ≤10 GB disk, ≤8 GB RAM and no custom image, so large data or a custom image needs a self-hosted sandbox or the Agent SDK. Pricing is tokens plus $0.08 per active session-hour plus $10 per 1,000 web searches. For API facts, check the bundled `claude-api` skill first, then platform.claude.com.
