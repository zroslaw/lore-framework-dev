# Plans and pricing

Checked 2026-10-14. List prices, monthly, before tax unless noted. Recheck before quoting.

## Two plan families (read this first)

- On **2026-10-12** SpaceXAI launched **The X Subscription**: one plan for Grok, Grok Bot, Cursor,
  and X Premium (x.ai news). cursor.com/pricing now shows only these plans, sold by "X Subscription
  Corp".
- "Nothing changes for existing SuperGrok, Cursor, or X Premium subscribers" (x.ai). Existing
  customers keep their Cursor plan, price, and features, or switch. The switch is permanent and
  rolls out gradually. New customers start on The X Subscription (Cursor help page).
- The Cursor docs (models-and-pricing, help pricing, Teams pricing) still describe the **Cursor
  plans**. Treat them as the plans of existing customers.

## The X Subscription (cursor.com/pricing)

| Plan | Price | Usage | Cursor features |
|---|---|---|---|
| Free | $0 | Limited | Limited agent requests |
| Plus | $8 | Basic shared pool | Cursor Agent, Grok models only, Grok API access |
| Premium | $30 | 4x Plus | Adds cloud agents and automations, Origin code hosting, Bugbot reviews, third-party models at API list price, Grok Bot |
| Super | $100 | 15x Plus | Adds priority model access at peak times |
| Ultra | $200 | 50x Plus | Adds earliest access to products and models |
| Teams | $30+/user | 4–50x Plus, pooled | Team marketplace, central billing, analytics, privacy settings, SSO, mixed seat types |
| Enterprise | Custom | Pooled | Invoicing, SCIM, spend and group controls, access controls, audit logs, priority support |

- One **weekly** pool shared by Cursor and Grok (Chat, Imagine, Voice, Bot). Top-ups after that.
- Third-party models are **not** in the pool; they bill at API list price from prepaid credit.
- x.ai says Premium bundles SuperGrok, Cursor Pro, and X Premium+ benefits, and that each plan has
  at least twice the Grok coding usage of the comparable Cursor plan.

## Cursor plans (docs; existing customers)

| Plan | Price | Pools | Notes |
|---|---|---|---|
| Hobby | Free | Limited | Agent, Chat, Tab with Auto |
| Start (India only) | ₹649, tax inclusive | Cursor Models only | Indian phone number; Grok at fixed medium effort, no Fast |
| Pro | $20 | Cursor Models + Other Models | Unlimited Tab, Bugbot, Cloud Agents |
| Pro+ | $60 | Both | More included usage |
| Ultra | $200 | Both | More included usage |
| Teams Standard | $40/user | Both, per user | Usage does not move between members |
| Teams Premium | $120/user | Both, 5x Standard | Free "Unpaid Admin" seats also exist |
| Enterprise | Custom | Pooled | See [admin controls](admin-and-enterprise-controls.md) |

- Pools reset **monthly** with the billing cycle; unused usage does not roll over.
- Cursor's own sizing hint: daily Agent users typically spend $60–$100 per month in total; power
  users $200 or more.
- Yearly billing exists (switch from the billing page). Upgrades apply at once; downgrades at the
  end of the period.
- **iOS in-app purchase**: monthly Pro, Pro+, or Ultra, billed by Apple. Users on an App Store plan
  must switch to The X Subscription before changing plans.

## Conflicts to state when answering

- Teams price: $40/$120 per seat (docs) vs "$30+/user" (X Subscription page).
- Usage period: monthly (docs) vs weekly (X Subscription; also Grok Bot usage).
- Names: "Hobby" and "Pro" (docs) vs "Free" and "Premium" (pricing page).
