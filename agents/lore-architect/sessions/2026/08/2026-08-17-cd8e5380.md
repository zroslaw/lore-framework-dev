# Running v40's gates after the fact, and shipping v41

v40 shipped without its real-engine gates — they had been deferred for a long time. This session
ran them: deterministic, lifecycle on Claude and Codex, the Keeper track, and the quality
benchmark. Cursor was excluded throughout at the user's instruction (no active subscription) and
is recorded as *did not run*, never as a pass.

The gates found one defect wearing four hats. In `version-check.md`, `summarize.md` (twice), and
`style.md`, the **terminal step of a procedure — the one that publishes or confirms the outcome —
was being silently skipped while every earlier step ran correctly**. The work was done; only the
reporting of it went missing, which is the failure an executor structurally cannot notice because
nothing ties those steps to an observable. Two of the four sat in prose whose "best-effort" or
"non-blocking" wording made skipping feel sanctioned. It was not one model's quirk: the publish
miss reproduced on both engines, the summarize misses were Claude-side, the style miss Codex-side.
It was also not confined to fixtures — this workspace's own git log showed the
`chore(lore): update framework to v<F>` commit present for v37 and v38 and absent since, with the
v40 stamp sitting uncommitted.

Before any of that could be measured, the Claude lifecycle shard turned out to be **unrunnable**.
Its plugin-identity gate asked the model which plugin root supplied its skills; on a machine with
the framework installed from the marketplace, the model inspects the plugin cache and reports that
path while `--plugin-dir` had in fact won. Every correct run read as a mismatch. That is the
failure `a-gate-cannot-be-a-model-self-report.md` already describes, left open on the one engine
the gate runs most. The verdict now comes from the engine's own `system`/`init` event.

Fixing the four defects took four rounds, because each successful fix exposed the next layer and
two of the fixes were themselves defective. The completion check written to catch "job half done"
passed a committed-but-unpushed repo. A style table listing concrete component names got copied
verbatim instead of substituted. Most instructive: three escalating rewrites failed to make
summarize's usage step run, and the cause was **location, not wording** — the agent pages a
492-line doc and never reached line 383, where the obligation lived. Moving the order into the
96-line `finalize.md` as Phase 3's opening action is what made it hold.

Three harness defects were the framework being right and the tests being wrong: a fixture pinned
to an absolute version that grew a 24-hop upgrade walk, a Keeper fixture registering a logical
`/var/...` path against a tool that realpaths, and a set of assertions reading the final message
for things the agent says mid-run. The last of these only became visible once Claude's transcript
was actually captured, and it had produced three consecutive false failures.

v41 shipped: framework tagged `lr--v1.41.0` at `0c8bef5`, dev repo alongside. The gate record is a
release-prep checkpoint accepted by explicit user direction, not a clean full-suite pass — the
final run had Claude green on the four modules that ran before the account hit its monthly spend
limit (precisely those carrying this release's fixes) and Codex at 7/9 with both failures
cheap-tier exact-string variance. The remaining Claude modules are uninterpretable, not red.

## Learning

### lore-architect

- **What mattered:** v40's four separate fidelity defects were one shape — the terminal step that
  publishes or confirms an outcome is what gets silently dropped, and the fix is an observable
  postcondition sited where the artifact is assembled, not more emphatic prose. The summarize step
  already carried a "models get this wrong" callout and was skipped anyway, with zero tool calls.
  Instruction *location* beats emphasis once a doc is long enough that executors page it and miss
  the tail; fractional step numbers are the same defect in miniature. Standing ship-discipline
  correction: the empirical gate runs *before* the tag, or the release records explicitly that it
  did not.
