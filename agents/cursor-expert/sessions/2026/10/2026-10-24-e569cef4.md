# Verified subagent nesting depth

The user asked whether subagents can spawn their own subagents and requested a live test. The main agent ran a controlled nesting experiment through Task: a level-1 subagent spawned a level-2 child, and the child was asked to spawn level-3.

The test showed that level-1 had Task and the child spawn succeeded. Level-2 reported that Task was not available, so it could not spawn further. A control run from level-1 spawning a grandchild directly still succeeded. The session therefore confirmed the documented one-hop nesting rule with a tooling explanation, not only policy text.

The user asked to save that finding into cursor-expert lore. Finalization added a reflection note, merged it into `lore/skills-subagents-and-commands.md`, and wrote this summary. No other agents participated.
