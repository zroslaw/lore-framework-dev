## Reusable creative brief

One feature-scoped Lore agent retains and curates context from ideation, exploration and research through PRDs, architecture/design documents and RFCs, implementation, tests, delivery and operational learning. It helps the whole team and supplies context to coding work. This is a product use-case illustration, not proof of automatic integrations or unprompted learning.

Show a product manager through customer insights and prioritization, an architect through alternatives and system diagrams, an engineer through implementation and tests, and an operations specialist through deployment, health monitoring and a runbook. The golden agent and its feature-context dossier connect them. Express roles with behavior and tools rather than literal job-title badges.

Preserve the main message at first glance while rewarding exploration. Small details should each express a different idea: a bridge-icon mug, architectural tradeoffs, acceptance criteria, accumulated notes, branches, production health and retained lessons. Avoid repeating generic slogans. Approved book titles: Roles & Purpose; Shared Knowledge; Reflection & Learning. Text and device geometry should be checked again before publication: generation may invent microtext or orient a screen awkwardly. Never intentionally place code or assistant windows on laptop backs.

Main title: Lore Agents. Subtitle: One feature. Shared context. From idea to delivery.

Logo reference: lore-framework/assets/logo.png relative to the workspace root. It is the same open-book/five-node-graph logo at each available resolution; only one source image was inspected. The logo remains in its owning repository.
