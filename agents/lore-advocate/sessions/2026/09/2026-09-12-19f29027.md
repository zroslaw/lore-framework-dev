# Replaced advocacy intuition with measured competitor evidence

The session opened with a publishing question. The user had drafted a long article about Lore Agents and wanted to know where to put it to reach the largest audience, and how to structure it. An initial pass produced a tiered recommendation — plugin directories first, then DEV Community as the article's canonical home, then LinkedIn, Reddit, and a deferred Hacker News launch. That recommendation later turned out to be partly wrong, and the session spent most of its length finding out why.

Before the research began, two pieces of infrastructure were dealt with. A Slack MCP server was installed against the user's own Lore Agents workspace; Slack does not support dynamic client registration, so the connection required creating a Slack app, enabling its MCP toggle, and exchanging an OAuth code by hand. The resulting token was written to a file and passed into the Claude Code config without entering the transcript. That connection was then used to pull two Slack messages containing the article draft, split across a character limit, and convert them to Markdown on the user's Desktop — verified lossless at 2,095 word tokens in identical order. The draft contains Agoda-specific material, so it was written straight to disk without being read into the session.

The research itself ran across five subagents. Two studied claude-mem, the most-starred project in the category; two studied mem0, the second; and one asked whether anything on the market already does what Lore Agents does. The findings converged on a single conclusion that contradicted the session's own earlier advice: content did not grow either project. claude-mem's two usage inflections were both installer changes, and its dev.to article arrived twelve months late with zero reactions. mem0's Show HN scored 201 points and produced fewer stars than a quiet week with no launch at all. The one tactic that compounded was becoming a dependency inside other people's frameworks.

Several assumptions were overturned mid-session. The claim that installers cause growth had to be narrowed when mem0 shipped a Claude Code plugin with no effect on its curve — the corrected rule is that friction reduction works only on the surface where the market already lives, which for Lore Agents is the coding-agent hosts. A watchers-to-stars heuristic used in the first study was withdrawn the same day when the second study showed it could not discriminate; the measurement was kept and the inference retracted symmetrically. The landscape study delivered the least comfortable finding: git-backed Markdown agent memory is no longer a differentiator, since Letta shipped it in February 2026 and Claude Code now has a native per-subagent memory field. It also found that "Lore" is already taken twice in this exact category, one of them by Notion.

The user's own proposal — publish the idea and approach first, externally, then the implementation — was pushed back on and then partly accepted. The agreed shape opens with a real breakdown and a concrete example, and delivers the approach fourth as the payoff rather than the entrance. The deciding argument came from the user's own evidence: explaining the approach internally at Agoda over a long period had produced little enthusiasm, so explanation had already been tested and had underperformed. Concept-first was kept for internal Agoda channels, where credibility is pre-established.

The session landed with a six-file market-research archive of roughly 210KB under the advocate's workdir, carrying an index with a corrections log, and with those findings merged into lore. Three conclusions were revised within the same day, each recorded rather than quietly overwritten. Two decisions remain open: whether to rename, and whether to pursue framework integrations. Two research gaps remain: Reddit could not be measured in either promotion study — unknown rather than zero — and Cursor Projects, which shipped two days before the research, was not evaluated.
