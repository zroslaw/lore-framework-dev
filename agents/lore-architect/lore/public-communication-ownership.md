# Public Communication Ownership

`lore-advocate` is the companion agent responsible for Lore Agents public positioning,
developer advocacy, PR work, and the communication strategy around articles, posts, demos,
campaigns, and audience learning.

`lore-architect` continues to own framework architecture, implementation, design history, and
product truth. When public communication depends on current behavior or architectural context,
the architect should supply or verify those facts for the advocate. Detailed communication plans
and channel strategy belong in the advocate's lore rather than being duplicated here.

For public-outreach work, use `lore-advocate` as the primary agent and attach or consult
`lore-architect` when a claim needs technical grounding.
