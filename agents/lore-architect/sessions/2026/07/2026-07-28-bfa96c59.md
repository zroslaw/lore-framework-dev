# Cursor merge switched to Task subagents

The session opened with a suspected inconsistency in the Cursor engine profile: the user believed the framework still claimed Cursor had no subagents, so merge (and related finalization work) was forced to run inside the host session. After boot as lore-architect, the host checked `docs/engines/cursor.md` and found the framing had already been corrected in v30 — Cursor *does* have `Task` subagents — but merge, recall, consult, attach, and conflict resolution still used a conservative serial host-side path because that path had been validated earlier, not because the mechanism was missing. Reflect stayed host-side on every engine by design (session context); merge was the Cursor-specific gap.

The user noted that this session itself was running in Cursor, which made the open "does `Task` accept a free-text brief?" question cheap to settle. A one-line `Task` probe returned successfully, confirming free-text `prompt` plus `subagent_type` (e.g. `generalPurpose`). With that evidence, the user directed a fix: update the Cursor profile so merge uses `Task` like Claude's `Agent` / Codex's `spawn_agent`. The host rewrote `lore-framework/docs/engines/cursor.md` accordingly — merge fans out via write-capable Tasks; recall/consult/attach/conflict remain serial for now; if `Task` is missing on an old CLI, stop rather than silently merging in the host.

Style skills (plain-language, follow-me, dialogue) were active for the later design turns. Finalization then reflected two topics, merged them via a real Cursor `Task` subagent (first use of the new path), and left unrelated dirty WIP in both repos untouched. The framework binding change is committed only for `docs/engines/cursor.md`; other local edits on `lore-framework` and non-`agents/` files on `lore-framework-dev` stay out of this finalize.

Next steps: optionally upgrade recall/consult/conflict to `Task` the same way; run Cursor lifecycle coverage that asserts tool-call logs for merge fan-out rather than outcome alone; keep the remaining serial host overrides until those upgrades land.
