# Corrected the curation claim while walking the market research

The session opened as a recall check. The user asked whether the agent remembered doing market research, and it did — the six-file archive under `workdir/market-research/` had been built earlier the same day. What the user actually wanted was the research told back to them as a story, fact by fact. The first attempt got that wrong: it produced a single long written-out article covering every finding at once. The user interrupted partway through and asked for it interactively instead. `/lr:style` was then set to plain, dialogue and follow, and the remainder ran as one fact per turn with the user steering between them.

Sixteen facts were walked in that shape, from the two studied projects through to how adoption should be measured. Several turns produced live side research. The user asked what CrewAI actually is, and then for a proper quick pass on it — a competitor that had appeared in the earlier archive only as the framework mem0 embedded itself into, never as a subject. That pass found a 58.4k-star, $18M-funded project whose crews are one-shot jobs, whose agents are three text fields that never change on their own, and whose money comes from a hosted enterprise platform billed by workflow execution. The same pattern mem0 runs. Further turns produced detail on Letta's MemFS — its three memory tiers, `persona.md` as an identity rather than a professional remit, and the discovery that Letta's "subagents" are memory maintenance workers rather than domain specialists.

Two things were overturned. The CrewAI pass found that CrewAI now ships a unified memory API with agent-level scoping, which the landscape study — written that morning — had scored as absent. The correction was logged in the archive index rather than edited into the study file, consistent with how that index already handles supersessions, and the row total moved 2.0 to 2.5. Separately, CrewAI's PyPI download curve turned out to carry a 95% overnight collapse on 2026-08-25, which no plausible reading attributes to users leaving. That became a fourth entry in the running list of ways adoption numbers have misled this archive, and a new rule: sanity-check download curves for step discontinuities before citing them.

The most consequential correction came from the user, not from research. The agent had been framing deliberate curation as *the user approves what the agent learns*, and contrasting that with the market's automatic capture. The user rejected the framing outright. Finalization being user-invoked is an implementation detail and is straightforwardly automatable — it can fire when a session goes stale — so human approval is not a differentiator and must not be claimed as one. What is defensible is the pair the user named: reflection runs over the **whole session**, so the agent can judge what mattered against how things actually turned out, where competitors extract from fragments (mem0 and CrewAI from individual task outputs, Letta's sleeptime process roughly every five steps); and the declared **role is the relevance boundary**, which is what keeps the knowledge base focused rather than merely large. The axis is focused versus everything, not manual versus automatic.

One smaller failure was instructive enough to keep. The strongest fact in the archive — zero of 981 agent definitions across the three largest subagent collections use any memory field — did not land when stated in its compressed archive form. The user asked for a complete rephrase, and the version that worked took five short steps of setup before reaching the number. Since that fact is intended to open public copy addressed to first-time readers, the sequence was recorded as a requirement rather than a preference.

The session closed two open questions and left others standing. The naming decision is settled: keep Lore Agents. The collision evidence survives only as an SEO constraint and as a reason public copy must state our stance plainly, since `BYK/loreai` markets the opposite philosophy under the same word. The user also gave a tagline direction — toward "a team of virtual self-learning and self-growing AI experts" — while explicitly deferring the final wording, so it was recorded as a direction rather than a decision. Cursor Projects remains unevaluated; it was offered and the user declined for now. Reddit remains unmeasured in both promotion studies, the framework-integration question remains open, and the tagline re-cut itself is still to be done.
