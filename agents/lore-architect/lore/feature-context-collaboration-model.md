# Feature Context Collaboration Model

The user endorsed a product-manager-facing illustration of a **feature-scoped Lore agent**:
one enduring collaborator carries the feature's accumulated context from ideation, exploration
and research through PRDs, design documents/RFCs, implementation, testing and delivery. Product
managers, technical architects, software engineers and operations specialists draw on that shared
understanding as their work changes across the lifecycle.

The distinction that makes the model useful is between the enduring feature agent and the
coding agents used for implementation. The feature agent supplies intent, research, decisions
and rationale that help engineers and their coding tools work coherently. It is not merely a
code-writing persona, nor a passive archive detached from the work.

This is an **endorsed use-case and communication model**, not evidence that a new automatic
integration has shipped or that all lifecycle context is captured without effort. Retention
uses Lore's deliberate reflection and merge curation. Scope an agent's responsibility to the
feature; avoid promising exhaustive memory or guaranteed delivery improvements.

The reusable visual directions and assets belong to `lore-advocate`, under
`agents/lore-advocate/workdir/artifacts/lore-agents-style-study/` in this repo. The architect
supplies accurate role, curation and collaboration framing; the advocate owns visual direction.
