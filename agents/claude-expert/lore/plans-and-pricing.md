# Plans and pricing

Source: https://claude.com/pricing, checked 2026-10-13 (documented). List prices; recheck before
use.

- **Free** ($0): chat on web, desktop, and mobile; web search, file creation, code execution;
  memory, connectors, Artifacts, Claude Design, Slides, Docs.
- **Pro**: $20/month, or $17/month billed annually ($200/year). Adds more usage, Claude Code,
  Projects, Claude Science, task handoff and scheduling, Dashboards (beta), more models, Claude in
  Chrome and Microsoft 365. Skills need Pro or higher.
- **Max**: from $100/month. 5x or 20x Pro usage, higher output limits, early access, priority at
  peak times, $100–200/month in API credits.
- **Team** (2–150 people): Standard seat $20/month billed annually ($25 monthly); Premium seat
  $100 annually ($125 monthly) with 5x Standard usage. Adds Cowork, Claude Code, @Claude,
  enterprise search, central billing, SSO, admin controls for remote and local connectors and
  plugins, desktop deployment, sharing and publishing of skills and plugins in the org, no
  training on content by default, and up to $500/month in pooled API credits.
- **Enterprise**: $20/seat/month billed annually **plus usage at API rates**, with user and org
  spend limits.

## Enterprise-only

Marked "No" for Team in the comparison table: role-based access, SCIM, audit logs, Compliance
API, custom data retention, a HIPAA-ready offering, domain capture, account migration by domain,
inference hooks, Claude Security (beta), full Fable access (Team: Premium seats only, at 50% of
weekly limits), ACH and invoicing, AWS Marketplace, committed-spend incentives, and customer
success. Marketing text also lists IP allowlisting and network-level access control.

## Training on data

Free, Pro, and Max users choose in their privacy settings. Team and Enterprise do not train on
content by default.
