# Unified Lore styles and prepared v35

The session opened with the user reviewing the Lore Framework command surface and asking how the
three communication-style commands could become one less confusing public skill. Earlier checks
also surfaced a stale temporary test-agent shortcut, a dangling Lore Architect cross-reference, and
a Chronicler version stamp that lagged the installed framework.

The architect and user settled on `/lr:style`: one public selector with internal `plain`,
`dialogue`, and `follow` components. No selector enables all three; an explicit selector list
replaces the complete active set; `off` clears it. The framework implementation added the thin
skill pointer and coordinator document, kept the three behavior documents as internal sources of
truth, removed the three old public skills and Cursor wrappers, and regenerated the Cursor catalog.
It also corrected Codex’s public skill syntax in the installation and engine documentation to
`$lr:<skill>` while retaining hyphenated personal agent shortcuts.

The release was prepared as cache-affecting v35: all four manifests now map to `1.35.0`, and the
release notes give the required Claude, Cursor, and Codex refresh steps. Focused static contracts
cover selector semantics, the one-visible-skill catalog shape, component reachability, manifest
documentation, and wrapper parity. The Cursor generator gained a real read-only `--check` mode,
repairing the earlier condition in which a purported check rewrote the tree. A lifecycle scenario
was added to the standard matrix and dry-run planned for all three engines, but the costly
real-engine matrix itself was intentionally not run at the user’s direction.

Finalization incorporated the implementation decisions into the Lore Architect’s style and release
knowledge, repaired the previously confirmed dangling `contributions-feature.md` reference, and
carried the Chronicler’s v34 stamp into its own clean worktree. All changes were ready for scoped
commits and pushes; the original production worktrees and their unrelated local changes remained
untouched.
