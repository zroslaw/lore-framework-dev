# Instructions, projects, and styles

Checked 2026-10-13. Documented, with the conflicts noted.

- **Instructions for Claude**: account-wide, set in Settings. In the new Cowork experience, Cowork
  global instructions merge into it.
- **Project instructions**: apply only inside one project. Free accounts can create up to five
  projects, but the help page conflicts on whether project instructions are paid-only. Check
  before answering.
- **Skills**: the current personalization page lists tone and format under skills
  ([extension platform](extension-platform.md)).
- **Styles**: shown on older help pages; the current personalization page no longer lists them.

Source: https://support.claude.com/en/articles/10185728-understanding-claude-s-personalization-features
