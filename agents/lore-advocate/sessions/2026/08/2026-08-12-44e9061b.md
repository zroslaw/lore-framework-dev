# Refined Lore Agents public positioning

The session opened by testing whether Lore Advocate was the right name and confirming the first
public rollout: clarify GitHub first, then prepare a short public-safe demonstration, share it with
a small group of potential early users, and learn before expanding distribution.

The user pushed the messaging beyond generic persistent memory. The chosen story starts with the
friction of current agent work: repeated context, repeated guidance, and agents that do not retain
the lessons of a working relationship. Lore Agents is now framed as a way to build a team of named
AI specialists that learns and grows with the user.

The README opening was rewritten around three concise ideas: why manual work can still feel easier,
how durable specialist knowledge addresses that problem, and the teammate mental model. The same
message was adapted for the Quick Start, marketplace copy, and Claude, Codex, and Cursor plugin
manifests. The public copy was committed and pushed to `lore-framework` on `main` as `e998d43`.

The Advocate's lore now preserves the positioning decision, including the important boundary that
learning is deliberately curated through reflection and finalization rather than being an
unqualified automatic claim. The next planned public artifact remains a short, public-safe demo
that proves the specialist model in a real workflow.
