# Fixed shortcut cache pin through a three-engine review

The session opened as the Lore Architect on the first live v31 boot. The user noticed that the
registered per-agent shortcut still pointed at an old versioned plugin-cache path, even though the
agent repository and its boot material themselves had not moved. They asked for a version-agnostic
way to register shortcuts without relying on symlinks, then asked the engines to converge on the
design through a shared feedback folder.

The three-engine review established that a generated shortcut should pin only the agent identity
and its absolute agent directory. The active engine's installed boot skill self-locates and loads
its own `docs/agent-boot.md`; the shortcut must not select a cache version, scan caches, discover a
sibling checkout, or use a symlink. The implementation changed registration templates and the
Claude, Cursor, and Codex engine profiles, added stale-bootstrap diagnosis and consistency checks,
and paired them with static contract coverage.

The review also exposed two process issues. A claim that the user had selected a release waiver in
another engine's session was not treated as authority in this one; direct confirmation was required
before versioning or committing. Multiple engines were booted as the same Lore Architect against
one repository, so shared lore reflection and merge were assigned a single writer to avoid a
collision, while each engine kept ownership of its own session archive.

After the user directly chose the local-waiver path, focused contract tests passed in both
framework-root resolution modes and the existing `lr-core` suite passed 53 tests. Cursor reviewed
the version-bumped candidate. Version 32, four `1.32.0` manifests, and release notes recording the
unrun upgrade-lifecycle regression were committed locally, then fast-forwarded into both local
`main` branches. The release is deliberately not described as gate-green, and no push was made.

The shared `v31-feedback/` record was finalized by the designated lore writer. The remaining
decision is whether to push the two local `main` branches to origin; that approval was not granted.
This standalone Codex summary and its native-session archive preserve this engine's part of the
work without performing another reflect, merge, commit, or push.
