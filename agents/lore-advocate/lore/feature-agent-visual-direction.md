# Feature-agent visual direction

For product managers, the approved visual story is a software team gathered around one golden feature agent that retains the feature's evolving context: ideation, exploration and research, PRD, design documents and RFCs, code and tests, then delivery and continued operation. The feature agent helps people and their coding assistants work with that context; the coding assistants are distinct from the enduring feature-context agent. This is a use-case illustration, not a claim of measured delivery improvement. It applies the practical, continuity-led [positioning](core-positioning.md).

## Approved detailed scene

The preferred master is a warm, detailed paper-crafted workshop. Keep a clear title and central feature-context focal point so the idea reads at a glance, with rich secondary details that reward exploration. The user tried simplification, then explicitly preferred restoring detail. Do not interpret this preference as a minimalist brand mandate.

Convey character identity through actions, tools and accessories, rather than job-title nameplates:

- Green product manager: customer insights, needs and product intent.
- Blue architect: system models, design choices and tradeoffs.
- Golden feature agent: the shared, accumulated feature context at the center of collaboration.
- Purple software engineer: actual code, tests and a branch sketch.
- Orange operations specialist: deployment checklist, production monitoring and a runbook, showing delivery, support and maintenance.

Each small object should communicate a different idea. Avoid duplicated slogans and diagrams. Useful details include a bridge-icon mug, acceptance criteria, recorded decisions and tradeoffs, and retained lessons. The approved three book spines read **Roles & Purpose**, **Shared Knowledge**, and **Reflection & Learning**. Never put coding-agent or code windows on laptop or monitor backs: rear lids remain plain and real front displays have plausible viewing geometry.

## Reusable style explorations

All four explorations were liked; none was selected as the final brand style:

1. Flat editorial illustration in restrained navy and teal.
2. Logo-inspired sculptural diorama in charcoal, ivory and gold, making the open book and five-node graph into a shared workspace.
3. Risograph poster using cobalt, red and yellow with print textures.
4. Atmospheric evening watercolor with warm, rich detail.

The existing logo source is `lore-framework/assets/logo.png`, relative to the workspace root. It is one open-book-and-five-node-graph design supplied in several dimensions; inspect one size rather than treating the files as different logos. Product spelling is **Lore Agents**, not LoRA.
