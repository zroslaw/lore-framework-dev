# User Feedback Working Style

One topic per piece of user feedback; the standing summary is below.

## Standing rules

- **User-feedback working style:** state a recommendation and its reason before asking a decision
  the user must own; short verdicts for settled decisions; confirm before durable mid-session lore
  writes, draft designs only when asked, "acknowledge" means do not act; minimalism governs design;
  keep safety guards small and fail-closed; a home agent is the best role fit. Reviews use Composer
  2.5 (unavailable on Claude Code; Cursor polish: `cursor-framework-polish-orchestration.md`). Route
  through the `feedback-*.md` topics (start with `feedback-commit-to-a-recommendation.md`,
  `feedback-mvp-minimalism.md`, `feedback-draft-only-when-user-triggers.md`).
